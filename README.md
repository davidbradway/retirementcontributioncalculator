# retirementContributionCalculator

This is a snippet of code with the Duke retirement contribution rates. It can be used to calculate the annual contribution that Duke will make on your behalf given your annual salary.

## Web UI

A browser-based calculator is available via Pages:  
**https://davidbradway.github.io/retirementcontributioncalculator/**  
**https://dpb6.pages.oit.duke.edu/retirementcontributioncalculator/**

Open `index.html` locally in any browser to use it without deploying.

## Python CLI

```bash
python calculate.py 109000
python calculate.py 80650 109000 133000
```
